# Contributing to PRESENCE

> 🇺🇸 English | 🇧🇷 [Português](#contribuindo-para-o-presence)

First off, thank you for considering contributing to PRESENCE! It's people like you that will make *"Nobody is alone"* a reality.

## Code of Conduct

We expect all contributors to be respectful, welcoming, and collaborative. Please read our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before participating. (Note: This file will be created soon).

## Who We Are Looking For

PRESENCE is an interdisciplinary project. We need brilliant minds from different backgrounds:

- **Unity / Unreal Engine Developers:** For 3D rendering, scene setup, and real-time pipelines.
- **AI Specialists:** For audio analysis, computer vision (pose estimation, lip-sync), and procedural animation.
- **3D Designers:** For mesh optimization, Gaussian Splatting, and realistic human modeling.
- **Mental Health Researchers:** To help us measure the psychological impact of presence in isolated environments.
- **Institutional Partners:** Space agencies, energy companies, defense organizations, and universities.

## How Can I Contribute?

This project is currently in the **concept and prototyping phase**. You don't need to be a coding expert to help. Here is how you can contribute:

### 1. Ideas and Concepts
The best way to start is by sharing your thoughts. Go to the **Discussions** tab and share your ideas on:
- How to solve the light/projection problem.
- Which environments should be prioritized (submarines, space, oil rigs).
- How to improve the AI animation pipeline.

### 2. Reporting Bugs
If you find a bug in our prototype or documentation, please open an **Issue**. Describe what happened, what you expected, and your environment (OS, device, etc.).

### 3. Code and Documentation
If you want to write code or improve documentation:
1. **Fork** the repository.
2. Create a new branch: `git checkout -b feature/your-feature-name`
3. Make your changes.
4. Commit your changes: `git commit -m 'Add some feature'`
5. Push to the branch: `git push origin feature/your-feature-name`
6. Open a **Pull Request**.

### 4. Translation
Help us translate the documentation into other languages. Currently, we support English and Portuguese.

## Tech Stack (Hypothesis)

As we are still in the early stages, the tech stack is a proposal. We are currently exploring:
- **3D Engine:** Unity or Unreal Engine 5
- **AI/ML:** Python, PyTorch, TensorFlow, MediaPipe, NVIDIA Audio2Face
- **Transmission:** WebRTC, 5G/6G networks
- **Hardware:** AR glasses (Meta Quest, Xreal), depth cameras (LiDAR)

## Language Policy

All code, code comments, and primary documentation must be in **English** to ensure global collaboration. However, communication in Issues and Discussions can be in English or Portuguese.

# Contribuindo para o PRESENCE

> 🇺🇸 [English](#contributing-to-presence) | 🇧🇷 Português

Antes de tudo, muito obrigado por considerar contribuir com o PRESENCE! São pessoas como você que farão o *"Nobody is alone"* se tornar realidade.

## Código de Conduta

Esperamos que todos os contribuidores sejam respeitosos, acolhedores e colaborativos. Por favor, leia nosso [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) antes de participar. (Nota: Este arquivo será criado em breve).

## Quem Procuramos

O PRESENCE é um projeto interdisciplinar. Precisamos de mentes brilhantes de diferentes áreas:

- **Desenvolvedores Unity / Unreal Engine:** Para renderização 3D, montagem de cena e pipelines em tempo real.
- **Especialistas em IA:** Para análise de áudio, visão computacional (estimativa de pose, lip-sync) e animação procedural.
- **Designers 3D:** Para otimização de malhas, Gaussian Splatting e modelagem humana realista.
- **Pesquisadores de Saúde Mental:** Para nos ajudar a medir o impacto psicológico da presença em ambientes isolados.
- **Parceiros Institucionais:** Agências espaciais, empresas de energia, organizações de defesa e universidades.

## Como Posso Contribuir?

Este projeto está atualmente na **fase de conceito e prototipagem**. Você não precisa ser um especialista em programação para ajudar. Veja como contribuir:

### 1. Ideias e Conceitos
A melhor forma de começar é compartilhando seus pensamentos. Vá para a aba **Discussions** (Discussões) e compartilhe suas ideias sobre:
- Como resolver o problema da luz/projeção.
- Quais ambientes devem ser priorizados (submarinos, espaço, plataformas de petróleo).
- Como melhorar o pipeline de animação por IA.

### 2. Relatar Problemas (Bugs)
Se você encontrar um erro em nosso protótipo ou documentação, abra uma **Issue** (Problema). Descreva o que aconteceu, o que você esperava e seu ambiente (SO, dispositivo, etc.).

### 3. Código e Documentação
Se você quiser escrever código ou melhorar a documentação:
1. Faça um **Fork** do repositório.
2. Crie uma nova branch: `git checkout -b feature/nome-da-sua-feature`
3. Faça suas alterações.
4. Faça o commit: `git commit -m 'Adiciona alguma feature'`
5. Envie para a branch: `git push origin feature/nome-da-sua-feature`
6. Abra um **Pull Request**.

### 4. Tradução
Ajude-nos a traduzir a documentação para outros idiomas. Atualmente, suportamos Inglês e Português.

## Stack Tecnológico (Hipótese)

Como ainda estamos nos estágios iniciais, o stack tecnológico é uma proposta. Estamos explorando atualmente:
- **Motor 3D:** Unity ou Unreal Engine 5
- **IA/ML:** Python, PyTorch, TensorFlow, MediaPipe, NVIDIA Audio2Face
- **Transmissão:** WebRTC, redes 5G/6G
- **Hardware:** Óculos AR (Meta Quest, Xreal), câmeras de profundidade (LiDAR)

## Política de Idioma

Todo o código, comentários de código e documentação principal devem estar em **Inglês** para garantir a colaboração global. No entanto, a comunicação em Issues e Discussions pode ser em Inglês ou Português.
